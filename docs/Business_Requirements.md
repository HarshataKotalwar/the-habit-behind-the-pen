# Business Requirements Document

## Project Goal

To analyze user behavior within PenFlow and identify the key factors that influence user retention and long-term engagement using data analytics techniques.

## Business Problem

PenFlow has experienced strong user acquisition but low long-term retention. Many users discontinue journaling within the first month, reducing engagement and subscription growth.

## Stakeholders

- Product Manager
- Head of Product
- Marketing Team
- Customer Success Team
- Executive Leadership

## Success Metrics (KPIs)

- 7-day Retention Rate
- 30-day Retention Rate
- Average Journaling Streak
- Average Weekly Journal Entries
- Reminder Engagement Rate
- Premium Conversion Rate
- Daily Active Users (DAU)
- Weekly Active Users (WAU)

## Key Business Questions

- What behaviors are associated with long-term user retention?
- Do reminder notifications improve engagement?
- Does maintaining longer journaling streaks increase retention?
- How does journaling frequency differ between retained and churned users?
- Which features are used most by highly engaged users?
- Is there a relationship between premium subscription and user retention?

## Data Requirements

The dataset should include user information, journaling activity, reminder interactions, mood tracking, streak information, subscription details, and engagement metrics required to answer the business questions.

## Expected Deliverables

- Research-backed synthetic dataset
- SQL analysis
- Python exploratory data analysis
- Interactive Power BI dashboard
- Business recommendations
- GitHub portfolio project
