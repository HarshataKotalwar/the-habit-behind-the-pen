# Project Charter

## 1. Project Title

The Habit Behind the Pen: An End-to-End Data Analytics Case Study on User Retention in a Digital Journaling Platform

## 2. Executive Summary

This project simulates a real-world data analytics engagement for PenFlow, a fictional digital journaling platform. The objective is to understand user behavior, identify factors that influence long-term retention, and provide data-driven recommendations to improve user engagement.

Because real user data is proprietary, this project uses a research-backed synthetic dataset designed using findings from peer-reviewed literature on journaling behavior, habit formation, and digital reminder systems.

The project demonstrates an end-to-end analytics workflow including business understanding, data modeling, dataset generation, SQL analysis, Python exploratory data analysis (EDA), interactive Power BI dashboards, and business recommendations.


## 3. Company Overview

PenFlow is a fictional subscription-based digital journaling platform that helps users develop a consistent journaling habit. The application offers mood tracking, guided writing prompts, personalized reminders, journaling streaks, and progress summaries to encourage long-term engagement and support personal well-being.

PenFlow has experienced rapid user growth through digital marketing campaigns. However, internal analytics indicate that many users discontinue journaling within the first month after signing up, creating a significant retention challenge for the business.


## 4. Product Overview

PenFlow is a mobile and web-based journaling application designed to help users build a sustainable journaling habit through a simple and engaging experience.

Key product features include:
- Daily journal entries
- Guided writing prompts
- Mood tracking before and after journaling
- Personalized reminder notifications
- Journaling streak tracking
- Weekly activity summaries
- Premium subscription with advanced insights.


## 5. Business Context

Although PenFlow has successfully acquired a growing user base, internal metrics show that many users stop using the application within the first month after registration. Low user retention reduces long-term customer value, affects subscription growth, and limits the effectiveness of product development efforts.

The Product and Leadership teams want to understand which user behaviors contribute to sustained engagement and which factors are associated with early churn. These insights will guide future product improvements and user retention strategies.

## 6. Business Problem

PenFlow is experiencing low user retention despite increasing user acquisition. The company needs to identify the behavioral patterns and product features that influence long-term engagement so that it can improve user retention and reduce churn.

## 7. Project Objectives

- Analyze user engagement patterns.
- Measure user retention over time.
- Identify behaviors associated with long-term retention.
- Evaluate the impact of reminders and journaling streaks.
- Build interactive dashboards to communicate insights.
- Provide actionable recommendations to improve user engagement.

## 8. Stakeholders

- Marketing Team

- Executive Leadership
- Data Analytics Team
  
## 9. Success Metrics (KPIs)

- 7-Day User Retention Rate
- 30-Day User Retention Rate
- Daily Active Users (DAU)
- Weekly Active Users (WAU)
- Average Journaling Streak
- Average Journal Entries per User
- Reminder Engagement Rate
- Premium Subscription Conversion Rate

## 10. Business Questions

1. What user behaviors are associated with long-term retention?
2. How do journaling frequency and streak length impact retention?
3. Do reminder notifications improve user engagement?
4. Which product features are most frequently used by retained users?
5. Is there a relationship between premium subscription and user retention?
6. How do engagement patterns change during a user's first 30 days?

## 11. Scope

This project focuses on analyzing user engagement and retention using a research-backed synthetic dataset. It includes business understanding, data modeling, SQL analysis, Python exploratory data analysis, interactive Power BI dashboards, and business recommendations.

The project does not include mobile app development, machine learning models, or real user data.

## 12. Assumptions

- The dataset is synthetic but designed using findings from peer-reviewed research.
- User behavior reflects realistic journaling patterns.
- Reminder effectiveness decreases over time if users ignore notifications.
- Longer journaling streaks are generally associated with higher retention.
- Mood improvements may occur after journaling but are not guaranteed.

## 13. Deliverables

- Research-backed synthetic dataset
- SQL analysis scripts

- Interactive Power BI dashboard
- Business recommendations
- GitHub repository with complete documentation.
